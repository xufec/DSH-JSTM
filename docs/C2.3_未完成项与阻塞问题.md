## §2 新增阻塞项（诊断会话发现）

### 2-a. LUA ERROR [11215] 伙伴列表解析报错（cmd=10999）

- **影响**：客户端解析 SC_11215 partner_list（53 条，2554 字节）时 Lua 报错；目前未观察到用户可见故障（伙伴面板未异常），但错误上报帧持续出现。
- **证据**：tcp.log 17:39:42 客户端发 `>> cmd=10999`，内容 `LUA ERROR: [208]错误[11215]伙伴列表`；调用链 game_start.luac → sys/gamenet.luac OnRecvMsg → common/debug_tool sendErrorToSrv。
- **后续建议**：下阶段伙伴面板数据对齐——服务端核对 11215 包结构（53 条伙伴字段布局）与客户端 partner_list 解析期望是否一致；可能需对齐字段顺序/类型/空值处理。

### 2-b. 钻石资产未推送（HUD 钻石=0 vs 金币 1800140 分离）

- **影响**：资产口径分离；商城"拥有"栏错读金币字段而非钻石字段，放大 G1 误判风险；钻石计价商品（定情玉镯 99 钻等）本地校验静默失败。
- **证据**：盘点 C4 商品详情"拥有(1800140)"=金币；诊断 f HUD 右上钻石=0；tcp.log gold=1800140 多次校验一致(17:39:41 DB persist)。
- **后续建议**：**待服务端**补推钻石资产（SC_10305 资产包补钻石字段 / 登录风暴资产补齐）；同时核对商城"拥有"栏 pay_type 字段映射（应按商品计价币别读对应资产）。

### 2-e. 活动顶栏图标世界锚定渲染配置项

- **影响**：首充/变强/挂机/限时返利/玩家回归 5 图标仅喷泉视角(scene 3675,1215)可见；相机平移后限时返利(1395,100)/玩家回归(1467,100)消失且触摸穿透场景地面；挂机面板因此 BLOCKED。
- **证据**：盘点 22-25,27；诊断 e：e_baseline_nopan/e_camera_pan1/2/e_camera_pan_back 对比——固定 HUD（首充1160/变强1248/挂机1320、左列、右列、底栏）不动，限时返利/玩家回归随相机消失。
- **后续建议**：客户端渲染配置——活动图标改绑屏幕层（view_manager/顶栏图标恒定屏幕层，不需服务端）；**本阶段不实施**。修后逐个抓 10924/10925 分派帧验证 47 活动图标。挂机按钮门禁（config_function）下阶段另查。
