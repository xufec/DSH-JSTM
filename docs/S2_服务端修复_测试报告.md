- 证据等级：服务端交付 STRONG（218B 帧 + 零 Lua 错误）；"天赋可见渲染" NOT_RUN / 未观测到。

## 二、项② GM setdiamond + 商城 99 钻购买闭环

### GM setdiamond（已证实）
- `GET /DSH_ADMIN/setdiamond?rid=1001&val=100000` → `{"ok":true,"old":0,"diamond":100000,"pushed":1}`。
- `gm.log` 双审计：setassets delta={'diamond':100000} + setdiamond old=0 new=100000。
- DB：`role_assets.diamond=100000`（写入成功）。

### 商城购买闭环（已证实）
- 商城打开（cmd=12831/12803），常用 tab 首项 = **定情玉镯，💎99**（mall id 2001，item_bid=25890）。
- 购买前 DB：`role_assets.gold=1800140, diamond=100000`。
- 点购买 → `>> cmd=16900 body=07 d1`（1233）+ `>> 13901`。
- **购买后 DB：`role_assets.gold=1800041`（=1800140-99），`diamond` 仍 100000**；`bag_items` 新增 `bid=25890, pos=13, quantity=1, ctime=now`。
- ⇒ **扣 99（gold）+ 物品 bid25890 入背包 + 服务端响应一致**。
- 证据：`s2_shots/14_mall_open.png`（商城）、`16_mall_changyong2.png`（99 商品选中，拥有 1800140）、`18_after_close_recharge.png`（角色面板 💎180万）。

### force-stop 重登持久化（已证实）
- `am force-stop` + monkey 冷启 → 重登回史莱克城（scene 10001，power=724112）。
- 重登后 DB 复核：`role_assets.gold=1800041`、`diamond=100000`、`bag_items bid=25890` 全部保留；tcp.log `<< 10302 资产刷新（补 diamond=100000）`。
- ⇒ 钻石/背包/金币持久化不丢。

### 实机发现（重要，如实记录）
- **本服商城「💎」位实际读 gold，不读 role_assets.diamond**：商城"拥有"显示 1800140（=gold 基线），购买 99 商品扣的是 `role_assets.gold`（pay_type=1 → gold，与 `shop_pay_asset→CODE_TO_ASSET[1]='gold'` 一致）。
- GM `setdiamond` 写的 `role_assets.diamond=100000` 是独立资产，**当前商城不读它做扣款**；它通过 SC_10302 尾部 diamond 字段下发（角色面板底部货币条 💎 实取 gold 显示，故 100000 未在该位单独呈现）。
- 即：GM 发钻石命令本身工作正常（写库+审计+推送+持久化），但"商城 99 钻购买"在本服实际是**扣 gold**，不是扣 diamond。此为 emulation 数据映射现实，非缺陷，按纪律如实记录、不强行改 pay_type。
