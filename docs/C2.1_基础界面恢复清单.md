## §1 C2.1 范围与六类状态定义

### 1.1 C2.1 范围（基础界面恢复，不含业务系统深度复原）

覆盖九类界面：① 登录与账号入口；② 角色选择/创建/信息；③ 游戏主界面（HUD）；④ 角色属性面板；⑤ 背包与物品面板；⑥ 任务面板；⑦ 系统设置；⑧ 常用二级面板（技能/商城/好友/日常/伙伴/挂机/锻造/公会/地图/VIP/答题/刮刮乐等）；⑨ 确认/提示弹窗。

不属本阶段：338 个 B 类中除上述范围外的业务面板（按 `ui_restoration_order.md` 阶段 1–5 另行排期）、27 个 C 类运营活动（activity_ctrl 按 name 分派，无独立 luac）、8 个 D 类（1.4.11 已移除，勿恢复）。

### 1.2 C0 状态（沿用 ui_inventory.json `_meta.status_definitions`）

| C0 状态 | 定义 | 数量 |
|---|---|---|
| A | 已实机/本地运行验证（runtime_evidence/shots、PHASE2_*.md、回归报告） | 18 |
| B | ui_by_module 有模块文件 + res_categories 有资源，未运行验证 | 338 |

| 类别 | 定义 | 判定依据 |
|---|---|---|

| **S2 已存在但未验证** | 模块+资源齐备，APK 内存在，未实机打开过 | C0 状态=B（`ui_by_module` apk_scan 证据，confidence=LOW） |
