## §1 工具修复与测试脚本说明

### 1.1 restart_server.ps1 修复（最小修复，非新功能）

**根因（实测，推翻此前归因）**：此前 C3.1-B 把失效归因为「python 路径含空格 `User Data` 致 WMI cmdline 解析失败」。本分片实测：

```
PS> (Get-Command python) | Select-Object CommandType, Source, Definition
CommandType : Alias
Source      = ""            ← 空
Definition  = ...\sandbox_runtime\bases\...\python\python.exe
```

本环境 `python` 是 **Alias**，`.Source` 为空、真实路径在 `.Definition`。原脚本 `$py = (Get-Command python).Source` 取到空串 ⇒ WMI cmdline 拼成
`cmd.exe /c "" "" "...\mock_server.py" 1>"..." 2>"...""` ⇒ cmd 把 `""` 当命令 ⇒ `'""' 不是内部或外部命令`。
**空格只是次要因素**：取到真实 Definition 路径后，既有 `cmd.exe /c ""py" "mock" 1>"out" 2>"err""` 嵌套引号对含空格路径实测工作正常（探针 `stdout.log` 得到 `Python 3.13.13`）。

修复 diff 详见 `docs_raw\c3_1_test_diff.md`。修复后实跑：杀旧 PID 30004 → WMI 拉起新实例 → 9000/8080 监听恢复 → `/DSH_ADMIN/getassets?rid=1001` 返回 200。

### 1.2 tools\c1_e2e_closed_loop.py 说明

- **结构**：`pack_frame/recv_exact` 复用 `audit_sc_live.py` 模式；`Client` 类封装登录（10001 FirstPack + 10 键 1110，强制 1.4.9 版本族）/建角（10101）/选角（10102）/RoleInit（10300）/资产查询（10302 解析 lev·exp·gold·coin·diamond）/任务接取（12402）/提交（12403）；`gm()` 走 HTTP `/DSH_ADMIN/*`；`restart_server()` 调子进程跑修复后的 `restart_server.ps1 -NoSmoke`。
- **9 环闭环**：全新账号 → 登录 → 建角 → 进场景 → 接任务 → 提交 → 发奖 → 经验/等级 → **杀 mock_server → 重启 → 重登断言一致**。
- **全新账号隔离**：`uid=c31test_<时间戳>`，rid 由服务端 `db_create_role` 分配（本次 rid=2001）；**绝不硬编码删除/覆盖 rid=1001**；测后动态枚举所有含 `rid` 列的表清理测试行，并删 `accounts` 行。
- **断言质量**：每项区分「TCP 连接成功」与「业务成功（SC code / DB 值 / 帧值）」。
- **首轮踩坑（已修，如实记录）**：GM `live_push` 会用 **HTTP-cfg(rid=1001)** 构建 10302/10301/10303 **广播到所有连接**，导致测试连接 socket 里滞留 rid=1001 的推送帧，被 `drain_until` 误读成自己请求的回包（tcp.log 实证：服务端对我们请求的实际回包 `lev=5 gold=12345` 是正确的）。修复：`query_10302` 前先 `_drain_rest(0.8)` 清空滞留推送。重跑后全部一致。
