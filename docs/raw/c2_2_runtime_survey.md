## 5. 新增发现

1. **F1 细化**：战力归零是"登录后首开面板"的时序问题（面板渲染早于 10304 到达），重开面板即恢复，HUD 战力始终正确。建议服务端在 10300 RoleInit 后主动 push 10304，或客户端在面板 onEnter 时主动请求。
2. **锻造当前装备属性为 0**（30）：当前装备 秘银长枪 物攻/法攻/命中均显示 0，但升级预览（黄金长枪 物攻213）正常。装备已穿戴但锻造视图未读到装备实例属性，与 F1 同源（装备属性 push 时序）。
3. **"提升"左侧按钮打开空白暗面板**（34）：无子项渲染，疑似未接线。
4. **"我要变强"条目为占位文本**（33）：列表项标题"我是技能名"，未接真实引导数据。
5. **戒指 tab 锁定**（11/13）：rail 上戒指点不切换，需婚戒/结婚系统前置。
6. **盘点期间网络极简**：tcp.log 显示打开各养成面板几乎不产生新 CS（仅心跳 1199 + 偶发 20100/10341 R191升级），说明面板数据均来自登录时 push 的本地缓存。
