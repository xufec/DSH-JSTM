## 〇、口径与规则说明

- **ui_id 规则**：ui_inventory.json 391 条原始条目无 id 字段，按 `{system_id}_UI_{系统内序号:03d}` 生成（如 `SYS_QUEST_003_UI_001`）；C2.1 实测发现 ui_inventory 未收录的补录条目用 `SYS_xxx_UI_90x` 后缀，可与系统内条目区分。
- **数据源**：`analysis/jstm_client_audit/ui_inventory.json`（391 条 C0 审计）；系统/服务端归属取 `systems_master.json` + `client_server_matrix.json`；协议取 `protocol_inventory.json`；实测回填取 `docs/C2.1_*.md` 三份与 `analysis/runtime_evidence/c2_1_shots/`。
- **八状态**：VERIFIED_WORKING=已实机运行验证可用；IMPLEMENTED_UNVERIFIED=代码已实现未实测；EXISTS_BROKEN=存在但运行有问题；PARTIAL=仅部分功能完成；RESOURCE_ONLY=仅确认资源；NEEDS_IMPLEMENTATION=有充分证据需实现/修复；BLOCKED=依赖或环境阻塞；UNKNOWN=证据不足。
- **状态映射（按证据复核，非机械套用）**：C0=A→VERIFIED_WORKING 初值，再按 C2.1 实测修正；C0=B→IMPLEMENTED_UNVERIFIED；C0=C（27 运营活动图标）→RESOURCE_ONLY；C0=D（8 个 1.4.11 已移除）→BLOCKED 并标注版本证据；技能面板(打开正常数据空)→PARTIAL；结拜(可达空响应)→NEEDS_IMPLEMENTATION；背包消耗品格缺失→PARTIAL；角色战力归零(重登恢复)→EXISTS_BROKEN。
- **优先级 P0–P3/TBD**：P0=启动/登录/选角/主界面关键路径；P1=角色属性/背包/任务/设置/商城核心常用；P2=养成/战斗/装备/挂机/地图/VIP；P3=活动/社交/辅助；TBD=证据不足（C/D 类等待取证；福利入口已 C2.4 取证闭环）。
- **多值字段**以「;」分隔；协议/字段/路径未确认处一律标 `UNKNOWN`，不凭文件名推断。
- **与 ui_inventory 的关系**：本表是其恢复视角的长期台账，互为引用；C2.1 实测结论优先于 C0 静态分类（冲突处以实机为准）。
