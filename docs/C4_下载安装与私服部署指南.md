## 5. 步骤 4 · 客户端改造（改包 → 签名 → 安装）

### 5.1 为什么要改包

原版客户端的所有服务端地址都指向**已下线的官方服务器**，且平台 SDK（ewan SuperSDK）初始化会因服务器不可达而弹出
「初始化失败,请检查网络」阻塞对话框，把 Lua 侧整体卡住。因此必须：

1. **跳过死掉的平台 SDK 初始化**（dex patch）；
2. **注入本地登录 Lua**（`server\dsh_fake_login.lua`），把登录/服务器列表/公告指向本机；
3. **替换下发配置**（`server\url_config_ewan.lua`），把 `URL_PATH` / `get_servers_url` / CDN 指向本机。

### 5.2 一键改包脚本

```powershell
# 联调版：客户端连 PC 的 10.0.2.2:8080（配合 server/mock_server.py 抓包）
pwsh tools\build_apk.ps1 -Src anzbao\jstm_1411.apk -NoEmbedded -Host 10.0.2.2 -Out patched\jstm_1411_pc.apk

# 探针/伪登录版（本工程主用产物，见 tools/build_fakelogin.ps1）
pwsh tools\build_fakelogin.ps1
```

`tools\build_fakelogin.ps1` 的流水线（**照抄即可复现**）：

| 阶段 | 动作 | 工具 |
|---|---|---|
| 0 | **Lua 语法门禁**（不过就不打包，绝不装坏 Lua） | `node tools\lua-check\check.js <lua>` |
| 1 | 注入 Lua 探针 / 本地登录逻辑 | `python tools\patch_fake_login.py` |
| 2 | 4 字节对齐 | `D:\Android\SDK\build-tools\34.0.0\zipalign.exe -f -p 4` |
| 3 | 签名（v1+v2） | `apksigner.bat sign --ks patched\dsh.keystore --ks-pass pass:123456 --key-pass pass:123456 --ks-key-alias dsh` |
| 4 | 安装并拉起 | `adb -s 127.0.0.1:16384 install -r` + `monkey` |

> ⚠ **踩坑**：签名务必用 `apksigner --out <新文件>`，不要"先 Copy 再原地签"——
> Windows 上刚创建的目标文件常被杀软/索引占用，会报
> `FileSystemException: 另一个程序正在使用此文件`。

### 5.3 手动改包等价命令（便于理解/排障）

```powershell
$BT = 'D:\Android\SDK\build-tools\34.0.0'
node tools\lua-check\check.js server\dsh_fake_login.lua
python tools\patch_fake_login.py anzbao\jstm.apk patched\jstm_raw.apk --base http://10.0.2.2:8080 --lua server\dsh_fake_login.lua
& "$BT\zipalign.exe" -f -p 4 patched\jstm_raw.apk patched\jstm_aligned.apk
& "$BT\apksigner.bat" sign --ks patched\dsh.keystore --ks-pass pass:123456 --key-pass pass:123456 --ks-key-alias dsh --out patched\jstm_signed.apk patched\jstm_aligned.apk
& "$BT\apksigner.bat" verify patched\jstm_signed.apk
adb -s emulator-5554 install -r patched\jstm_signed.apk
```

### 5.4 客户端关键全局（由 `url_config_ewan.lua` 下发）

| 全局 | 类型 | 取值 | 消费方（反汇编确认） |
|---|---|---|---|
| `URL_PATH_ALL` | table | `:get(platform)` → `{update,voice,register,is_shenhe,platform}` | `file_update.luac proto#8` |
| `URL_PATH` | table | `URL_PATH_ALL:get(PLATFORM_NAME)` | `file_update` / `denglu_ctrl` |
| `get_servers_url` | **函数** | `BASE .. '/gateway/mobile/json'` | `denglu_mgr.luac proto[22]` |
| `get_notice_url` | **函数** | `BASE .. '/notice.json'` | `notice_view.luac proto[9]` |
| `CDN_URL` / `url_res_config` | string | `BASE .. '/cdn/'` | `res_download_mgr` |
| `UPDATE_VERSION_MAX` | number | `NOW_VERSION`（令 `now_ver >= target_ver` 恒真，跳过热更） | `file_update proto#17` |

> ⚠ **`get_servers_url` / `get_notice_url` 必须是函数**。写成字符串会导致客户端抛
> `attempt to call global 'get_servers_url' (a string value)`，并中断登录界面构建
> （`login_panel` / `server_panel` / `user_panel` 全部不再加载）。

## 11. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `adb: device offline` | MuMu 休眠 | `adb connect 127.0.0.1:16384`；仍失败则重启实例 |
| 客户端卡「网络重连中…」 | 服务端重启后重连未成功 | `am force-stop` 后重新拉起 |
| 客户端停在标题页不进游戏 | 未点到「进入游戏」 | 实测按钮中心 `(1272, 980)`（2560×1440） |
| 弹「初始化失败,请检查网络」 | 平台 SDK 未跳过 | 改包必须带 `-SkipSdkInit`/`build_apk.ps1` 的 dex patch |
| `attempt to call global 'get_servers_url'` | 下发的 `url_config` 缺全局定义 | 确认 `server/url_config_ewan.lua` 是**生产版**（含 `URL_PATH`/`get_servers_url`），不是探针版 |
| 进游戏后角色模型不显示 | 目标图与存档坐标不同图 | 已由 `_send_10200` 的"切图用目标图默认点"修复；若复现查 `tcp.log` 的 `10200 bid=` 与 `10201` 是否同图 |
| 移动被拒绝 / 坐标被拽回 | 移动校验用了旧图的 MapBlock | 已由 `_current_bid()` 优先取 `_last_enter` 修复 |
| 面板显示异常 | 客户端 debug 包渲染态 | 见 §12 缺口，非服务端数据问题 |
| 端口被占（9000/8080） | 多个 mock_server 实例 | 用 `tools\restart_server.ps1`（会先杀干净） |
| `RUN_TESTS.ps1` 乱码 | PS5.1 解析 UTF-8 失败 | 用 `pwsh` 7 运行 |
| GM 写端点返回 401 | 未填/填错 GM Token | 顶栏填 `dshgm`（或 `DSH_GM_TOKEN` 的值） |
