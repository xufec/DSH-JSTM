## §1 阻塞项清单

### B1 面板 X 关闭坐标偏移（环境差异）

- **现象**：静态校准文档记面板 X=(2200,70)，在 emulator-5554（MuMu 12，2560×1440）实点无效；实际命中需 x+30px=(2270,70)。
- **影响**：自动化点击关闭面板会误触面板内容；不影响人工操作与功能正确性。
- **证据**：N17/N18/N30/U9 标注；b33→b34 用 (2270,70) 成功关闭商店。
- **后续建议**：更新 `analysis/calibrated_ui_coords.md` 头部基准，注明 emulator-5554 横屏适配偏移 +30px；换分辨率/实例需重校准（R6）。

### B2 登录 UI 未完整直接验证

- **现象**：登录标题屏本次实机见到（绝世唐门+进入游戏+切换账号/公告，b07），但 platform/server/user panel、选服、选角/建角流程在假登录（IS_PLATFORM_LOGIN=false）旁路下不出现。
- **影响**：登录链 UI 仅验证"标题屏→进入游戏→自动重连"主路径；平台登录、选服列表、建角/选角界面未直接取证。
- **证据**：b07；清单 §2.1/§2.2 S2/S4 条目；导航 N2/N3/U2/U3。
- **后续建议**：C2.2 若需验证，临时改注入块 IS_PLATFORM_LOGIN=true 或用空角色账号触发建角流程；本阶段不重打包故未做。

### B3 技能面板空数据（依赖服务端推送）

- **现象**：技能面板可开但技能列表空。
- **影响**：技能面板 UI 框架在，但无技能数据展示。
- **证据**：前期 runtime_verify §2；清单 §2.7 skill panel。
- **后续建议**：移交 C2.2——服务端补 CS_10302/10401 族技能推送，或客户端从 10300 初始化链补拉技能列表。

### B4 端口/实例差异已澄清

- **现象**：前期文档记 MuMu adb=127.0.0.1:16384；本环境实际实例为 emulator-5554（`adb connect emulator-5554` 在线）。
- **影响**：坐标/连接命令需用 emulator-5554；非功能阻塞。
- **证据**：环境确认阶段 adb devices；restart_server.ps1 标准流程。
- **后续建议**：后续文档统一标注 emulator-5554；若切回 16384 实例需重连+重校准坐标。
