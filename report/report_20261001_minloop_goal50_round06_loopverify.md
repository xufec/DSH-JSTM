## 二、★ 首跑失败暴露的真实问题（诚实记录）

```
失败：★ 10020 奖励与 APK 配置逐项相等  — 实得 {"coin":1320,"exp":550,"hero_exp":500}
期望：coin+1290 / exp+500 / hero_exp+500
```

**原因**：我把测量窗口开在**击杀之前**，于是窗口里同时包含了
① **击杀奖励**（`KILL_REWARD`，本服标注为 **`[TEST_ONLY]` 占位值**：+30 coin / +50 exp）与
② **任务奖励**（真实配置驱动）。

**处置**：把 `before20` 快照移到**击杀之后、提交之前** ⇒ 窗口只覆盖提交 ⇒ 断言精确成立。
同时把这件事写进注释，避免以后再犯（**占位奖励不得与配置驱动的任务奖励混算**）。

> 这不是服务端 bug，而是**测试口径 bug**——但它有价值：它证明"占位击杀奖励"确实在发，
> 且金额与真机配置无关（提醒后续要么标清、要么改成配置驱动）。
