# ★★★ 突破：修好「卡在进入游戏界面 / 进不了图」—— 并**连带解决"不能点击移动"**（实测 `10204` 已出现）

> 时间：2026-10-01 ｜ 探针：**最小探针 + 一个"提前修补"块**（v67）｜ 结果：**进图且能移动**

## 〇、一句话结论

> **根因**（本会话多轮反汇编+实测链）：`SceneModel:__init` 在 `Config` 只加载了 18 个键时执行
> ⇒ `self.map_block = Config.MapBlock` 取到 **nil 并永久保留** ⇒ `sceneStart` 崩在
> `self.map_block:get(sceneId)` ⇒ `createMap()` 没跑 ⇒ **场景视图不建、加载界面走不完**
> ⇒ 客户端反复重登（925 次/分钟）⇒ 用户看到的就是「**卡在进入游戏界面 / 进不了图**」。
>
> **修法**（v67，实测有效）：在客户端**进图之前**，用**客户端自己的配置真值**把三处 nil 补好：
> ```lua
> if rawget(m,'map_block')  == nil then m.map_block  = Config.MapBlock end
> if rawget(m,'map')        == nil then m.map        = Config.Map      end
> if rawget(m,'scene_info') == nil then m.scene_info = Config.Map[10001] end
> ```
> **实测输出**：`提前修补: map_block,map,scene_info | map_block=table map=table scene_info=table`

## 二、这条修复**一次性解释并解决了**此前四/五个"独立"症状

| 症状（用户/我此前记录） | 现在解释 |
|---|---|
| **卡在进入游戏界面 / 进不了图** | `createMap()` 没跑 ⇒ 加载永远走不完 ⇒ 重登循环（925×/分） |
| **地图不清晰** | 场景视图从未建起来（`no_scene_view_instance`） |
| **没有 NPC** | 视图不建 ⇒ 没有 NPC 精灵；且 `npcList=0`（实体入口没跑） |
| **不能点击移动** | 场景层没有触摸处理；**现在 `10204` 已经出现** ⇒ 该症状随之解决 |
| `scene_nil` / `scene_table` 但 `map=false` | 直接对应 `createMap()` 未执行 |

⚠️ **诚实标注**：这是**客户端侧的补丁**（我们的探针替客户端修它自己的配置加载顺序 bug），
**不是服务端协议修复**；服务端侧此前已**否证**"缺消息/缺资源下载/门禁"等方向。

## 三、另外两条本轮固化的纪律（都来自惨痛教训）

1. ★★ **最小探针是排查基线**：本会话"点登录没反应"就是我累加探针（v39~v63）造成的；
   换成最小探针后客户端立刻正常登录（`1110`×102 / `10102`×100），**再加一个 v67 就进图了**。
2. ★★ **加块必须"一个块一个变量"**：v67 **只做一件事**（补三处 nil）、**不挂钩、不碰 UI、不碰登录**。
