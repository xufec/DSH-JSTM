| 步骤 | 结果 |

| 生成 v61 探针（python 脚本，从 `analysis/1.4.9/task/map_npc.json` + `server/_mapnpc_10001.json` 取 19 个真值 NPC 的 bid/坐标，写进 Lua 表） | ✅ 脚本报告"已生成…嵌入 19 个真值 NPC（scene 10001）" |

**根因判断（诚实）**：脚本用 Python `%` 模板拼 Lua 表字面量（`local ROWS = { %s }`），
拼接出的**表字面量结构有误**（`'}' expected near 'local'` 指向表未正确闭合）。
这是**我的生成脚本的问题**，不是客户端/服务端的问题。
