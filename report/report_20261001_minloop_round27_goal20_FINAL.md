# 最小回环 · 第 27 轮（goal round 20/20）—— 收官：可用手段已穷尽，卡点闭口在客户端原生 `Send`

> 时间：2026-10-01 ｜ 目标 APK `anzbao/jstm.apk`（1.4.9 / `com.shiyue.dldl.ewan.qihoo`）｜ 环境：MuMu + adb(root) + frida 17.18 + tcpdump

---

## 〇、结论（一句话）

> **目标未达成**：真机客户端**收发通道已打通**（连接/登录/心跳/角色数据实测成立），
> 但它**从不发送 `10102/10103`**；三重独立证据把责任**排除在服务端之外**，
> 并把丢失点**闭口在客户端 Lua→原生这一段（`UserMsgAdapter:Send`）**。
> 最后一轮尝试用 **frida 在原生层**观测，**钩子再次被自证为盲**（同期客户端写了 7 条 HTTP 上报而钩子 0 命中）
> ⇒ **本环境下没有可用的原生观测手段** ⇒ 判定 **blocked**。

## 一、本轮（最后一轮）做了什么

| 步骤 | 结果 |
|---|---|
| 起 frida-server（7555 实例，root） | ✅ |
| 附加主进程（pid=4598，全模块挂钩 1330 个地址） | ✅ `模块=294 钩子地址数=1330` |
| **自证要求**：同期服务端必须出现探针上报 | ✅ `同期服务端 DSH_PROBE 增加 7 条` |
| 钩子命中 | ❌ **`全部写=0（fd 数=0）`** |
| 工具自动判读 | ✅ **`INCONCLUSIVE（钩子瞎）`** —— 并明确"本条不得用于'客户端没写过 :9000'的结论" |
| 结论 | **原生观测手段在本环境不可用**（与第 5 轮同一现象：钩子报 0，同窗口客户端实际写了 1575 条 HTTP） |

> 本轮**没有**产出新的"客户端没写 10102"的证据 —— 原有的那条结论来自**服务端 recv 尺寸**与**链路层抓包**，
> 与 frida 无关，因此**不受本次钩子失灵影响**。

## 二、★★ 目标第一优先项（"帧是否到 socket 层"）——**两侧已闭环**

| 观测面 | 手段 | 结果 |
|---|---|---|
| **服务端** | 字节级 `recv` 日志 | 帧尺寸**只有** `{10:364, 23:29, 225:5}` = `1199`/`10001`/`1110`；`未解帧=0` |
| **链路层** | `tcpdump -i any`（160s / 21110 行） | 游戏服对端**只有 `10.0.2.2:9000`**（窗口内仅 1 次 SYN）；`10102/10103` **没有发往任何目的地**；其余外部流量全是第三方 SDK |
| **客户端 Lua** | 自证版包装（安装留据 + 身份比对 + 无过滤） | `10102`：`WriteHeader=true`、`Encode=true`、`Send` **被调用**、`SendProtocal=true`；`game_net_id=1` 有效 |

⇒ **`1199/10001/1110` 到达 socket 层；`10102/10103` 从未到达，也没有发往别处。**
⇒ 丢失点**唯一**落在 **`UserMsgAdapter:Send` 的原生实现**（Lua 层全部成功、适配器**无可枚举字段**）。

## 四、该怎么优化 / 怎么继续（交接清单）

1. **若仍要走客户端原生这条路**：需要**换一个能拦住该 APP 写的观测手段**
   （本环境的 frida 钩子对它是盲的；可试：换 frida 版本/`--enable-` 选项、
   在 `libcocos2dlua.so`/supersdk 的原生符号上直接挂钩、或 LD_PRELOAD 式注入）。
   **纪律**：任何"0 事件"结论**必须先自证钩子有效**（同时 hook 一个必然发生的写，本项目已有模板）。
2. **若换客户端版本/实例**：本会话已见"16384 实例曾进场景、7555 实例始终不行"的差异，
   值得先做**两实例差异对比**（存档 `local_srv_id`/`last_login_accounts`、资源完整性）。
3. **服务端侧已可交付**：`server/minloop/` 可直接用于"最小回环"验证与回归
   （45/45 自检 + 292 真机帧回放）；**新增专用 handler 时记得同时跑
   `audit_dedicated.py` 与 `selftest.py`**。
4. **可选低风险推进**：把本服已实现的 `12400/12402/12403/20002/…/10500` 用
   **协议级回放**（真机帧）继续做端到端校验，不依赖客户端 UI。
