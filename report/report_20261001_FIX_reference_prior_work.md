## 〇、一句话结论

> ★ **这些症状在 DSH 里确实出现过，而且已经被定位过——但当时也没有真正修好**：
> 关键文档 `analysis/1.4.9/movement/movement_test.md`（"1.4.9 角色移动 —— 测试记录（已验证）"）
> 把**根因**写得很清楚：
>
> ```lua
> -- scene_controller.move (proto[37]) 开头两道门禁
> if self.model:isOnTeamFollow() then return end
> if not self.model:isLoadState() then return end      -- ★ 卡在这里
> ```
> **`isLoadState` 恒为 `false` = "地图资源异步加载尚未完成"**（`mapResAsyncList`，
> 由 `scene_view proto[35]/[36]/[65]`、`proto[28]` 维护）——
> 这是**客户端内部**的加载门禁：
> - **不能点击移动**：`move()` 一进门就 `return` ⇒ **不发 `CS_10204`**（与我今天实测"`10204` 0 次"完全对上）；
> - **地图不清晰 / 没有 NPC**：地图资源没装完 ⇒ 场景没建完 ⇒ 渲染不出东西。
>
> ⇒ **"地图不清晰"与"不能移动"是同一个根因的两个症状**，不是两个独立问题。
