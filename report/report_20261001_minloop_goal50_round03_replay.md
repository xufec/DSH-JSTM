## 一、这个 harness 做什么 / 怎么跑

1. **每条源日志各起一个全新最小回环服**（`free_port()` + `tempfile.mkdtemp()` + 临时 DB，与 `selftest.py` 同款进程内模式），
   把该日志里**真实客户端帧按原顺序**灌进去（含 `protocol/fields.json` 里无 CS/SC 定义的命令也照发，保证顺序完整）。
2. **每个回环关键帧**（`Session.LOOP` 11 条：1110/1199/10001/10102/10204/10300/10502/12400/12402/12403/20002）
   在**发包前后**对 `Store` 快照（`missions`/`bag`/`roles`），逐帧记录服务端应答（SC 严格性、code、msg）
   与**副作用差分**：任务新建/推进、进包（含叠包 +n）、货币 coin·gold·coupon·exp·hero_exp 增量。
3. **诚实纪律**：只断言真实帧 + `server/mission_config.json` 能推出的东西；抓包缺帧（无 10102/12402/12400/20002/10502）
   或怪物 id 不在 `server/config.json` 时记 **replay context disconnected**，不当 bug；验不了的一律打 **UNKNOWN**。
   拒绝分类：`怪物不在场`/`任务不存在` ⇒ disconnected；`条件未满足（n/m）` ⇒ honest_reject。
