## 一、本轮验证（真机，`logs/minloop/live16_stdout.log`）

```
清零角色后重启客户端:
  .. 1110 该账号角色列表为空 ⇒ 如实回空（交给客户端走"创建角色"）
  << 1110 SCAccountLogin account=None roles=0 least_career=0xff 12 bytes      ← ★ 空列表 + 职业全可选

本轮客户端命令: {10001: 1, 1110: 1}          ← ★ 只发了这两个
  10101(建角)=0 | 10102(登录角色)=0          ← ★★ **不再自动登录角色**
```

**读法**：客户端**停在"账号登录 → 拿到（空）角色列表"这一步**，
即**应当显示"选角 / 创建角色"界面**（因为列表为空）—— 这正是用户想要的状态。
它**没有**再自动进游戏（`10102` = 0）。

> ⚠️ **我看不到屏幕**：界面是否真的出现"创建角色"按钮、可选职业是否正确显示，**需要你确认**（我这边是 UNKNOWN）。
> 服务端侧该给的都给了：`roles=[]`（列表空）+ `least_career=0xff`（职业可选）+ `10101` 已实现（可建角）。

## 二、现在的完整登录流程（服务端侧能力）

```
① 网关 /gateway/mobile/json  →  服务器列表（未变）
② >> 1110（账号登录）        →  << code=1 + roles=[] + least_career=0xff    ← 空列表 ⇒ 客户端展示"创建角色"
③ >> 10101（创建角色）        →  校验（名字 1..12、不重名、career 1..8、sex 0/1）
                                ⇒ 建行（新 rid = 最大 rid+1，lev=1）
                                ⇒ << code=1 + rid + srv_id
                                ⇒ **立刻重推 1110**（列表里出现新角色）
④ >> 10102（登录角色）        →  << code=1 + 推 10200/10201（进场景）        ← 已有实现
```
