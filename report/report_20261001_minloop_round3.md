## 二、★ 两个界面状态（本轮第一次"看得见"）

### 2.1 只调 `openView()` ⇒ 仍在**加载界面**

```
Label[100%]            adb=1448,1413
Label[玩命加载中...]     adb=1229,1413
Label[建议您在wifi状态…] adb=1280,821
Label[提示信息]         adb=1280,621
?[nil] size=204x57     adb=978,981     ← 隐藏对话框的两个按钮
?[nil] size=204x57     adb=1578,981
```
**含义**：加载条 100%，tips 仍是"玩命加载中…"（**没变成"开始游戏…"**），
且有一个**隐藏**的"建议在 WiFi 下游戏"提示框，两个按钮在 (978,981)/(1578,981)。

### 2.2 `openView()` + `beginGame()` ⇒ 直接进**游戏内 HUD 壳**

```
Label[背包] adb=2258,288
Label[称号] adb=2258,517
Label[戒指] adb=2258,746
Label[时装] adb=2258,976
Label[魂骨] adb=2258,1205
```
**含义**：`beginGame()`（`game_start.lua` proto#2）会把客户端**跳过登录**直接推到主界面 HUD，
而此时**并没有服务器连接** —— 所以它是个"壳"，点了也不会发协议帧。
