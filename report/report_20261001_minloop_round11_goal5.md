```

smk  = sm.vo_false                       ← SceneModel.vo 为 false
sceneInfo = table_roles_nil_npcs_table_mons_table_elems_table_bid_number_scene_id_nil_srv_id_nil

sceneData = table_sceneId_0_...          ← 随后掉回 0（重试/回退）

```

**读法**：
1. 服务端**确实推了** `10200/10201`（服务端日志有 `<< 10200` / `<< 10201`）；
2. 客户端**也接收了**（`recv_48`，且 `sceneData.sceneId` 一度变成 `10001`）；
3. 但 `elementList`/`scene_info.roles` 是空的 ⇒ **`10201` 的载荷没有被解析成实体**；
4. 于是 `scene_nil` → 客户端不断重试（`10102` 发了 2 次、`1110` 发了 7 次）⇒
   也就**走不到任务/战斗**（`12400/12402/12403/20002` 全缺）。
