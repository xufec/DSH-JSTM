## 一、★ 本轮两次自我更正（都保留在案）

### 更正 A：我的救连条件的**取反错误**
- 上一轮写的是 `if conn and …` ⇒ **只有在"已连上"时才重试**，而真正需要救的是 `conn=false`。
- 实测：那一版**服务端 0 次连接**、客户端 0 条命令 ⇒ 条件确实写反了。

### 更正 B：改成"每次都重连"是**更糟**的做法
- 改成每 10 拍 `restartNetManager + AsyncConnectLoginServer + ConnectLoginServer` 之后：
  服务端 **10 次 `=== 连接`**，但客户端**一个帧都没有**（`{ }`、种类 0）。
- 根因：**反复 `restartNetManager` 会在"客户端自己的 OnConnect 该跑"的时刻把 net 对象换掉**；
  握手入口（`OnNetAsyncConnected` / `requirehand` / `request1110Role`）**都返回 true 却无字节**
  （客户端日志：`handshake[OnNetAsyncConnected=true,requirehand=true,request1110Role=true]`）。
- 这与本项目早前结论一致：**不要接管客户端自己的流程**。

### 最终配方（本轮验证）
```
跳 net_manager:Stop  →  initInstance()  →  restartNetManager()（一次）
→ 若 30 拍后仍未连上，则**只救一次**：SetLoginServerInfo + AsyncConnectLoginServer
→ 连上之后**什么都不做**，让客户端自己的驱动完成 10001/1110
```
**实测**：连接 11 次（期间多次重连是客户端自己的行为），客户端发出 **`10001`×1、`1110`×1**，
探针 `recv_26` ⇒ **客户端在收发**（此前那一版是 0 帧）。
