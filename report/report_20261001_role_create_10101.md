## 三、★ 本轮我自己犯的一个错（诚实记录，第三次同类）

首跑时 **`1110` 与 `10101` 双双不回应**。原因：我新写的两处又用了
**`(row or {}).get('x')`** —— 而本服 `self.store.one/all()` 返回的是 **`sqlite3.Row`**（**没有 `.get`**）：

```
!! 回环处理 1110 异常: AttributeError: 'sqlite3.Row' object has no attribute 'get'
!! 回环处理 10101 异常: 同上
```
修法：一律按 Row 取值（`row['m'] if row else 1000`、`r['career'] if r else 0`）⇒ **143/143**。

> **教训（已第二次踩，值得升级为硬规则）**：
> **凡 `self.store.one(...)` / `self.store.all(...)` 的返回值，只能按 `sqlite3.Row` 用（`r['列名']`），禁止 `.get(...)`。**
> 这类错误的表征也固定：**该命令"完全没有应答"**（异常被 per-message 的 `except` 吞掉）——
> 因此**新增 handler 必须同时加断言**，否则就是"悄悄不工作"。
