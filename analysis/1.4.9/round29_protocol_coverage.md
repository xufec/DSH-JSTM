### 批次 2：42 条**通用安全默认响应**

**依据**：这 42 条的 SC 定义**不含未解子表 `D|Dsc*|`** ⇒ 可按规格生成安全响应。

**实现**：`_build_default_sc(cmd)` 读 `protocol/fields.json` 的 SC 规格，按类型填默认值：
```
第一个字段名为 code  → 回 1（成功）
string              → 空串
table(...)          → 空表（计数 0）
uint8/16/32         → 0
```

**★ 诚实原则**：**不编造任何具体数值/内容** —— 客户端拿到"成功但空"不会卡死，
也不会显示假数据；将来有真实数据再逐条填。
