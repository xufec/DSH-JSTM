## 二、★★ 门禁 G：`tools/audit_dedicated_really.py`

对**最近新增的专用命令批次**做**双重检查**：

1. **静态**：该命令号是否出现在 `if cmd == N:` 或 `if cmd in (…N…)` 里
2. **动态**：发一条，**读 `tcp.log` 的新增行** ⇒ 必须是**专用日志**，
   不能是 `兜底响应` / `默认响应`

```
== R167 13xxx(62) ==  静态: 无 ✓   动态: 0 条走兜底 ✓
== R168 13xxx(25) ==  静态: 无 ✓   动态: 0 条走兜底 ✓
=== 门禁 G 结果: PASS（有问题批次 0）===
```

★ 用法：`python tools/audit_dedicated_really.py [--cmds 13322,13301]`
★ **新增批次时，把命令号加进 `BATCHES`**（这样门禁会随时间累积覆盖）。
