## 二、★ 又是我自己的验收错误：`string` 的**长度前缀占 2 字节**

`verify_chair_wing_rest.py` 第一版把回显读成 **0**（期望 101/1/202），报 FAIL；
但**手工验证时是对的**（`len=5`）⇒ 说明**脚本里的偏移算错了**：

```python
# 错：off = 1 + len(msg)          ⇒ 漏了 string 的**长度前缀本身占 2 字节**
# 对：off = 1 + 2 + len(msg)
```

`SC{code:u8, msg:string, surface_id:u16}`：
```
[0]      code
[1:3]    msg 的 u16 长度前缀
[3:3+n]  msg 内容（n=0 ⇒ 无）
[3+n:]   surface_id
```

⇒ 修后 101/1/202 **全部读对**。

> ★ **纪律**：**`string` 字段占 `2 + len` 字节**（含长度前缀），
> 算偏移时**别只加内容长度**。这是本会话里"手写解析器出错"的**又一例**——
> ⇒ 结构断言一律用**门禁的权威解析器**（`audit_body`），手写解字段只用于**取值核对**。
