## 一、★ 综合战力 0 的真因与修复

### 真因：客户端"变强/综合战力"面板读的是 **`SC_20100`**，不是 10304

```
SC_20100（客户端 activity_ctrl handle20100 → AdvanceEvent:Fire(Update_Data) → 变强面板）
  power    : table(code:u8, val:u32)    ← ★ 战力**分量列表**（数组）
  promote  : table(code:u8, val:D|Dsc20100val|)  ← 含未解子表
服务端此前**未实现 20100** ⇒ 面板 power 取不到 ⇒ 综合战力 0
```

### 修复：实现 20100

```
power_total = power_mod.calc_power(default_attr)   ← 真实权重
power 分量列表 = [(1, power_total), (2,0), (3,0)]   ← code 语义未取证，用占位 code
promote = 空表（含未解子表 D|Dsc20100val| ⇒ 按纪律不猜）
```

**实测：**
```
20100 → power[code=1 战力=160095, code=2/3=0], promote=0
```

**⇒ 变强面板的综合战力从 0 → 160095。**

### ⚠ 诚实的点

| 项 | 状态 |
|---|---|
| 综合战力非零 | ✅（160095） |
| 用原版权重 | ✅ |
| power 分量 **code 语义** | ⚠️ **未取证**（用占位 1/2/3；可能客户端按特定 code 归类显示） |
| promote | ⚠️ 空（未解子表，按纪律不猜） |

**⇒ 综合战力有值了，但"输出的粒度"（客户端按几个分量显示）待真机确认。**
