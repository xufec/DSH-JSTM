## 三、★★ 修掉一个我自己写的"**假失败**"

`10504` 第一版写的是：

```python
if _gain and _gone:        # ← 判据掺了"收入"
    ...  ; code=1
else:
    code=0, '背包里找不到这些物品'
```

而背包里那件物品的 `item_config[bid].value == 0` ⇒ `_gain=0` ⇒ 走 `else` 回 **`code=0`**，
**但物品其实已经被删掉了** —— 那是**状态改了却说失败**（比"假成功"更糟）。

**修**：判据**只看实际删掉了几个**（`if _gone: code=1`），**售价 0 也是成功**。

> ★ 这是本会话第 **3** 次在"状态已改 / 未改"的判断上出错（前两次：R112 的"只扣钱不给物"、
> R113 的"判据数行数而非 `SUM(quantity)`"）。**教训**：凡涉及"改了没有"的判据，
> 必须**以数据库前后对比为准**，且**两个方向都要检查**（改了却说失败 ≠ 没改却说成功）。
