## ✅ 已修（4 项）

### ⑤ + ⑦ 背包/仓库/伙伴空间 —— **已开放**

**取证**：`bag_volume` 表里 `bag_code=1 → 155`、`4 → 135`、`5 → 6`；
但**客户端从没问过 `10552`** ⇒ 它本地容量是未知/0 ⇒ 界面显示"可用空间很少"。

**修复**：
```sql
bag_volume: 1→200, 2→200, 3→200, 4→200, 5→200
config: partner_volume=200, partner_volume_open=200, bag_volume_default=200
```

**实测：**
```
SC_10552 背包  old=200 new=200
SC_10552 仓库  old=200 new=200
SC_11200 volume=200 volume_open=200      ← ★ 伙伴空间
```

**★ 新增 `11200`（伙伴背包）** —— 由 `game/hero/hero_equip_ctrl.luac` 注册（`11200~11205`），
**真机反复请求、原先无人应答** ⇒ 这就是"伙伴空间开放不了"。
`partner_bag` 含 **6 个未解子表** ⇒ 按纪律发 **0 项**。

### ① 聚宝盆不消耗钻石 —— **已修**

**取证**：原实现**先抽后入包，完全不扣费** ⇒ 可无限抽。

**修复**：按 `config.jubaopen_cost` 先校验、再扣费，不足则 `code=0` + 非空 msg。
```json
"jubaopen_cost": { "asset": "gold", "per_draw": 100 }
```
**币种依据**：`gold` = **钻石**（实测界面读数定死，见 `dsh_admin.ps1` 头部定论记录）。

**实测：**
```
抽取前 钻石 = 910314  →  抽取后 910114      （2 次 × 100 = 减 200 ✓）
```
