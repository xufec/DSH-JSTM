## 五、与"服务端解锁"的关系

当前服务器 `mission_chain()` 的实现与该依赖形态**一致**：

```
链 = 主线按 bid 升序，且 lev <= 玩家等级
解锁指针 = 链上第一个未完成（mission_status != 3）的位置
下发 = 从指针往下 N 条（mission_chain_max，默认 8）
```

**⇒ Phase 5 实测已验证**：提交 `10010` 后指针前移到 `10020`，再提交 `10020` 后前移到 `10030`。
