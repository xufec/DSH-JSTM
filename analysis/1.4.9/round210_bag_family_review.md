## 二、★★ 误报 1：**`10500` 是"服务端主动推送"（push），不是"请求-响应"**

```
L5401:  handler.request.sendall(pack_frame(10500, w_u8(bc) + build_bag_items(items)))
L5402:  log('tcp.log', '  << 10500 SC_10500 bag push bag_code=%d items=%d'
…（13965 / 14383 / 14528 / 14601 / 15273 / 15311 / 15405 / 15761 等 **9 处推送**）
```
★ **⇒ `10500` **有真实实现**（`build_bag_items`），只是**没有 `if cmd == 10500:` 的请求分支**
   ⇒ **扫描的"无专用分支"是误报** ❌

★ **⇒ 验证**（`10502` 同族，有请求分支）：
```
  10502 bag_code=1: len=159 消耗=159 err=None ｜ ★ items=4      ← 真实背包物品
```

★★ **⇒ 结论**：**"背包族"本来就实现了**（`10500` 推送 + `10502` 请求）✓

> **★ 纪律第 50 条**：**"服务端推送型"命令没有"请求分支"** ——
> 扫"无专用分支"时**必须排除"推送型"**（本项目的 `10500`、`12405`、`12505` 等都是推送）。
> ★★ **判据**：**grep 该命令号** ⇒ **若有多处 `sendall(pack_frame(N, …))` ⇒ 是推送型** ⇒ **不算未实现**。
