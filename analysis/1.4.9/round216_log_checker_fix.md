## 一、★★ R216 的错：**静态扫源码里的日志行**

`tools/check_log_precise.py`（**静态扫**）报 **3 组"日志写 0 但真实值非 0"**：

```
cmd=10922  act_list  真实值=9   （SC table）
cmd=11712  code      真实值=1   （SC uint8）
cmd=14701  code      真实值=1   （SC uint8）
```

### ★★★ 逐条查明：**全是"失败/实验分支"的日志**

| 行 | 日志原文 | 真相 |
|---|---|---|
| **L13951** | `10922 SC_10922 act_list=0 (R49 实验: disable_10922)` | ★ **实验分支**（**正常路在 L13946 `act_list=%d`**）|
| **L15273** | `11712 SC_11712 code=0 (%s 不足 %d/%d)` | ★ **失败分支**（我发包时成功了）|
| **L13982** | `14701 SC_14701 code=0 (钻石不足, gold=%d)` | ★ **失败分支** |

★ **⇒ 静态扫会把"**从未执行的失败分支**"的日志当成"主日志"** ❌

## 二、★★★ 修正：**运行时抓日志**（`tools/check_log_runtime.py`）

```python
base = len(open(LOG).readlines())     # ★ 抓日志基线
b = ask(cmd)                          # ★ 发包
new = open(LOG).readlines()[base:]    # ★ 取"实际执行"的那条日志
vals, _ = parse_fields(sc[cmd], b, 0) # ★ 按权威 SC 解析回包
for mm in re.finditer(r'([a-z_]+)=0\b', line):
    if vals.get(fld) != 0:  → 不一致
```

### 实测

```
★ 静态命中"日志含 `xxx=0`"的命令: **45 个**
★★ **运行时日志写 0 但回包真实值非 0**: **0 组**
   （无）✓ —— 所有日志与回包一致
```

★★★ **⇒ 结论**：
   - **`19400` 的日志问题（R215 修的）是**孤例**（**只有它写死了 0**）；
   - **45 个命令的日志**全部与回包一致** ✓
   - **R216 的"静态扫"方法是错的**（**抓失败分支**）⇒ **R216b 的"运行时抓"才对** ✓

> **★ 纪律第 58 条**：**"检查日志"必须"运行时抓"，不能"静态扫源码"** ——
> 一个命令**有多条日志**（**成功/失败/实验分支**）⇒
> ★★ **静态扫会把"从未执行的失败分支"的日志当成"主日志"** ⇒ **误报**。
> ★★★ **判据**：**用"日志基线 + 发包 + 取新增日志"**（**那才是"实际执行"的那条**）。
