## 一、方法：一次遍历建"命令 → 归属"映射（`tools/cmd_unknown.py`）

**做法**：扫 `anzbao/jstm.apk` 里**所有** `.luac`，对每条 `KSHORT` 指令取 16 位操作数
（LuaJIT `KSHORT` 4 字节 = `[op][A][D_lo][D_hi]`，`D` 就是那个常量 —— 与 `tools/_cmp_versions.py` 同款口径），
**一次遍历**建出 `命令号 → [文件]` 的全量映射（命中 **4970** 条），再压成**系统名**（优先 `xxx_ctrl`）。

再叠加三列：**我们的处理状态**（专用 / 默认 / 未开放 / 无）、**真机频次**、**SC 字段摘要**。

```bash
python tools/cmd_unknown.py                     # 只看"未实现 + 真机发过"（按频次）
python tools/cmd_unknown.py --all               # 全部未实现的
python tools/cmd_unknown.py --by-system         # ★ 按系统聚合
python tools/cmd_unknown.py --cmd 10407         # 单查某条
python tools/cmd_unknown.py --by-system --md out.md
```
