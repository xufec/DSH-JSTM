## 一、★★ 取证：R161 说的"`10810` 中文乱码" **不是服务端的问题**

R161 我留下待办："`10810` 存入的 `subject` 是乱码 ⇒ 中文编码链路有问题"。

**本批取证**（先看字节，不猜）：

```
DB: subject='�'  ⇒ 字节 ef bf bd（UTF-8 的 U+FFFD 替换字符）  ← "解码失败"的产物
    content='��\x00\x04内容'                                  ← 把后面的字节也吃进去了
```

再看**我自己的测试包**：
```python
10810: bytes([1]) + struct.pack('>H', 2) + '测试'.encode() + …
                                    ^^^^ '测试'.encode() 是 **6 字节**，我却写了 **2**
```
⇒ **服务端按声明的长度读，完全正确**；**是我的测试包长度字段写错了**。

**修后**：
```
DB: (7, '测试', '内容')   ← ★ 中文正常
```
