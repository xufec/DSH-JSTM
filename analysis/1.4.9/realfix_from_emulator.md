## 二、本轮修复（全部基于真实会话差集）

### 2.1 定位方法

**用真实日志做差集：客户端发过的命令 − 服务端回过的命令 = 未应答。**

```
第一次会话：未应答 33 / 73
```

### 2.2 区分「不需要应答」与「真未实现」

**这一步**很关键** —— 33 条里有**本来就无需应答**的：**

| 类别 | 命令 | 说明 |
|---|---|---|
| **仅 CS（客户端上报/通知）** | `10001` `10300`(CSRoleInit) `10999` | **协议只有 CS 没有 SC ⇒ 不需要服务端回应** |
| **含未解子表 `D\|Dsc*\|`** | `11300`（`Dsc11300partner_list`）等 | **按项目纪律：不实现** |
| **真正未实现** | 其余 | 需逐条取证后实现 |

### 2.3 本轮实现的 3 条（定义干净、无未解子表）

| CMD | 定义 | 实现 |
|---|---|---|
| **`11301`** | `(空) → SC{lev:u8, num:u8}` | 取 config（默认 0），**不编造** |
| **`11700`** | `(空) → SC{free_times,all_times,reward_coin,one_name,one_coin,record_server,record_self}` | 取 config，表为空则发空表 |
| **`10923`** | `{id:u16} → SC{id,status:u8,int_args:table(val:u32)}` | 回 `status=0` + **空表**，**不编造** |

**实测：**
```
11301 -> 2 字节   ✓
11700 -> 16 字节  ✓
10923 -> 5 字节   ✓
```
