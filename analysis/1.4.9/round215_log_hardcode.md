```python
if cmd == 19400:
```

## 二、★ 修正 + 建立检查器

### 修正

```python
log('tcp.log', '  << 19400 SC_19400 bag=%d stage=%d mingge_list=%d (%d bytes)'
    % (_bc, mingge_stage_init(), len(_mg or []), len(_out) + 6))   # ★ 真实条数
```
**实测**：新日志 `mingge_list=2` ✓

### 检查器：`tools/check_log_vs_reply.py`

```
★ 可疑（日志里写死 `xxx=0`）: **57 处**
★ 逐条实测（看"日志声称 0"的字段在回包里是否非 0）:
   L8245  cmd=20023 field=type        ｜ 回包 8 字节，全零=True     ← ★ 日志正确
   L8775  cmd=16900 field=charge      ｜ 回包 6 字节，全零=True     ← ★ 正确
   L8856  cmd=10932 field=double      ｜ 回包 8 字节，全零=**False** ← ⚠ 需核对
   L8868  cmd=17312 field=code        ｜ 回包 30 字节，全零=False    ← ⚠ 需核对
   …
```

★ **⇒ 大部分"全零=True"**（**日志正确**）；**少数"全零=False"需精确核对** ——
   ★★ **注意**：**"全零=False" ≠ "日志错"**（**回包里可能有别的字段非零**）⇒
     **必须"解析出日志里那个字段的真实值"才能判定**（**下一批**）。

> **★ 纪律第 57 条**：**日志里的"数值"必须从"实际编码的变量"取，不能写死** ——
> `19400` 的日志写死 `mingge_list=0` ⇒ **它成为"误导源"**（**R203 因此误判**）。
> ★★ **判据**：**日志与回包必须"同源"**（**同一个变量**）；**写死的字面量一律可疑**。
> ★★★ **做法**：**用 `tools/check_log_vs_reply.py` 批量核对**（**日志声称 0 ⇒ 回包是否真的 0**）。
