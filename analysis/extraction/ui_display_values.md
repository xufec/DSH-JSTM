**截图**：`shots/user_assist/xiulian_panel_35of50.png`

**UI 显示值**：

| 项目 | UI 显示 |
|---|---|
| 修炼选中项 | 抗控修炼 LV.22，选中"怒吼" |
| 修炼进度条 | **35/50** |
| 消耗栏 EXP 数值 | **空白**（无数值显示） |
| 拥有栏 EXP 数值 | **空白**（无数值显示） |

**关键结论：修炼 UI "50"语义定论（CONFIRMED）**

- **50 = 修炼进度条本级满值**（35/50 进度）
- **35 = 当前修炼经验**（对应我们下发的 bid=10822 exp=35）
- 两者是不同字段，无矛盾：进度条正确渲染，但消耗/拥有 EXP 数值栏仍为空
- 此前 INFERENCE 闭环：35=当前修炼经验 ✅ 验证通过；50=本级进度满值 ✅ 新确认

**新缺口**：
- 消耗栏/拥有栏 EXP 数值均空白（UI_DISPLAY 证据）
- exp=35 进度条正确，但消耗/拥有 EXP 数值仍未下发，待定位字段
