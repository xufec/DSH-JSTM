## 4. 根因分析

### 客户端命令链（基于 proto_defs + mock_server 注释）

```
客户端预期流程：
1. 用户点"自动巡逻"
2. 客户端发 CS_15405（挂机轮次查询）
3. 服务端回 SC_15405{loop_count:u16}
4. 客户端发 CS_15400（挂机启动）
5. 服务端回 SC_15400{code,msg}
6. 客户端发 CS_15402{mission_bid}
7. 服务端回 SC_15402{mission_bid,map_bid,x,y}
```

### 当前状态

- mock_server 注释显示 15400/15405 已"移出"（R48）
- 客户端点击按钮后**未发送任何 CS 命令**（仅心跳）
- 推测：客户端检测到服务端未推送前置数据（如 12400 补推链），按钮处于"本地禁用"状态
