## 三、实机 UI 导航知识固化（本轮踩出来的，写下来省下一轮的时间）

| 事实 | 值 | 说明 |
|---|---|---|
| **登录后默认打开「背包/装备面板」** | 冷启 + **不点任何东西**，截图即 1.79 MB 且 OCR 出 武器/戒指/头盔/衣服/护/鞋子/腰带 + 综合战力 | 这是**前面几轮"点什么都没反应"的真正原因**：点击全落在这块面板上 |
| **该面板关闭 X** | **(1900,40)** | 点了立刻回世界视图（4.8 MB）|
| `50级礼包` 弹窗关闭 | (2360,680) | 项目旧表已有 |
| **魂技** | **(1710,1320)** | 触发 `10621` ✓ |
| 宗门 | (1960,1320) | 触发宗门面板（宗主/人数/创建宗门 …）✓ |
| 充值/VIP | (2110,1320) | 打开 VIP 面板（**用户已说跳过**）|
| 日常 | (30,200) | 触发 `13781/13786` |
| 排行 | (30,400) | 触发 `12901` |
| 好友 | (150,1000) | 触发 `13300/13321` |
| **世界地图面板关闭 X** | **(2060,85)** | 项目旧表记的 (2210,85) **关不掉它**；BACK 也关不掉 |

**方法论（三条"点不动"的真实原因，按出现频率）**
1. **有面板盖在上面**（最常见）→ 先截图 OCR 看当前是什么界面，用面板自己的 X 关掉；
2. **面板是本地打开、不发 CS** → 此时"没有新 CS"**不能**推出"点击没生效"；
3. **BACK 对某些面板无效**（世界地图要 4 次 BACK 都不动）→ 必须用面板自己的 X。
