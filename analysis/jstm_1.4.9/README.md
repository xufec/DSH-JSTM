|---|---|

| **服务端已实现** | **83** |
| 真机客户端**发过** | **128** |
| 真机服务端**回过** | **70** |
| **真机未应答** | **66** |

**⇒ 关键结论：**
- **客户端实际用到的只有 128 个**（占总协议 7.7%）—— **我们不必实现全部 1652 个**
- **已实现 83 个，覆盖了客户端行为的 70/128 ≈ 55%**
- **未应答 66 个**，其中 **61 个是有 SC 的（真正该实现）**，5 个是仅 CS（客户端上报，**本就不需要应答**）
